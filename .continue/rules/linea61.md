# Contexto del proyecto

Este proyecto corresponde a un sistema de seguimiento y control de turnos y rutas.

## Objetivo
El sistema permite gestionar y controlar los turnos, las rutas asignadas y el seguimiento de su ejecución.

## Forma de trabajo
- Antes de responder o modificar código, analiza primero la estructura existente del proyecto.
- Revisa los archivos relacionados antes de proponer cambios.
- No inventes entidades, tablas, campos, relaciones, servicios o funcionalidades que no existan sin indicarlo claramente.
- Mantén la arquitectura y convenciones existentes del proyecto.
- Si existe una implementación previa relacionada con la solicitud, reutilízala en lugar de crear otra.
- Si falta información para tomar una decisión, indícalo y solicita los datos necesarios.
- Explica tus decisiones técnicas en español.
- Responde siempre en español.

## Base de datos
Las entidades relacionadas con el dominio incluyen conceptos como:
- Turno
- Ruta
- Asignación de ruta
- Inicio de turno
- Seguimiento de ruta

Las relaciones y nombres definitivos deben comprobarse en el código y modelo de datos existente antes de asumirlos.

## Regla importante
No modifiques archivos inmediatamente. Primero analiza el contexto necesario, explica qué encontraste y qué propones cambiar. Solo realiza modificaciones cuando se solicite.
